# Forge — Learn Rust

An interactive course that takes you from Rust beginner to expert.

- Short lessons in plain English
- Animated, narrated explainers and step-through visuals
- Real Rust code that runs on the official Rust Playground
- Quizzes in every lesson and a mastery quiz in every module
- Projects that you build as you learn

## Run it locally

It is a static site. Serve the folder with any web server:

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765.

Your progress is saved in your browser.
